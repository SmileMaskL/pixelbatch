========================================
PixelBatch 앱(모바일 웹앱) - 아주 쉬운 설명
========================================

■ 이전 버전과 뭐가 다른가요?
전에 드린 건 컴퓨터에서 파이썬으로 실행해야 하는 프로그램이라
설치/명령어가 필요해서 어려우셨을 거예요. 이번 건 그냥 "링크"입니다.
폰 브라우저로 링크를 열면 바로 앱처럼 씁니다. 설치, 파이썬, 명령어
전부 필요 없습니다.


■ 지금 당장 1분 안에 폰에서 테스트해보는 방법 (가장 쉬움)

1) 컴퓨터에서 https://app.netlify.com/drop 사이트를 엽니다. (회원가입 필요 없음)
2) 이 폴더(PixelBatch-App-2026-09-10) 전체를 그 화면에 마우스로
   드래그해서 놓습니다.
3) 몇 초 뒤 "https://무작위이름.netlify.app" 같은 주소가 생깁니다.
4) 그 주소를 내 폰으로 보내서 (카카오톡 나에게 보내기 등) 폰 브라우저로
   열어보세요. 사진 선택 → 처리 → 다운로드까지 실제로 다 됩니다.

이 주소는 임시 보관용입니다. 나중에 진짜로 계속 쓰려면 아래
"영구 주소 만들기"를 해주세요.


■ 앱처럼 홈 화면에 아이콘으로 추가하기

- 안드로이드(크롬): 주소를 열고 오른쪽 위 점 3개 → "홈 화면에 추가"
- 아이폰(사파리): 주소를 열고 하단 공유 버튼 → "홈 화면에 추가"

그러면 진짜 앱처럼 아이콘이 생기고, 눌러서 실행됩니다.


■ 영구적으로 쓸 수 있는 무료 주소 만들기 (GitHub Pages)

1) https://github.com 에서 무료 계정을 만듭니다.
2) 오른쪽 위 "+" → "New repository" 로 새 저장소를 만듭니다.
   (이름 예: pixelbatch)
3) 저장소 페이지에서 "Add file" → "Upload files" 를 누르고
   이 폴더 안의 모든 파일(index.html, style.css, app.js, sw.js,
   manifest.json, icons 폴더)을 통째로 올립니다.
4) 저장소의 "Settings" → 왼쪽 메뉴 "Pages" 로 들어갑니다.
5) "Branch"를 main으로 선택하고 저장합니다.
6) 1~2분 기다리면 상단에
   "https://내아이디.github.io/pixelbatch/" 같은 주소가 나옵니다.
   이 주소가 평생 쓸 수 있는 내 앱 주소입니다. (무료, 서버 관리 필요 없음)


■ 돈 받고 파는 방법 (Pro 잠금 해제)

1) https://gumroad.com 에서 무료로 판매자 계정을 만듭니다.
2) 새 상품(Product) 만들기 → 종류는 "Digital product" 선택
   - 가격 설정 (예: 4,900원)
   - "Generate a unique license key per sale" 옵션을 꼭 켜세요
     (이게 켜져 있어야 손님마다 다른 열쇠가 자동 발급됩니다)
3) 상품을 저장하면 주소가 생깁니다. 예: gumroad.com/l/abc123
   여기서 맨 뒤 "abc123" 부분이 필요합니다.
4) 이 폴더 안 "app.js" 파일을 메모장으로 열어서 맨 위쪽에 있는

     const GUMROAD_PRODUCT_PERMALINK = "REPLACE_WITH_YOUR_GUMROAD_PERMALINK";

   이 줄을 찾아서 따옴표 안을 방금 확인한 "abc123" 같은 걸로
   바꿔주세요. 예:

     const GUMROAD_PRODUCT_PERMALINK = "abc123";

5) 바뀐 app.js 파일을 GitHub Pages(또는 Netlify)에 다시 올리면 끝입니다.

이제 손님이 결제하면 Gumroad가 자동으로 열쇠(라이선스 키)를 보내주고,
손님은 앱 안에서 그 열쇠를 입력하면 무제한으로 쓸 수 있게 됩니다.
저희는 결제나 열쇠 관리를 위한 서버를 따로 켜둘 필요가 전혀 없습니다
(전부 Gumroad가 대신 처리합니다).


■ 이 앱이 다른 앱들과 다른 점 (홍보 문구로 써도 됩니다)

- 사진이 서버로 전송되지 않고 폰(브라우저) 안에서만 처리됩니다
  → 개인정보가 새어나갈 걱정이 없습니다
- 사진을 "한 장씩"이 아니라 여러 장을 한 번에 처리합니다
- 자주 쓰는 설정(인스타그램용, 스마트스토어용 등)을 "프리셋"으로
  저장해서 다음에 한 번에 불러올 수 있습니다
- 워터마크를 사진 전체에 반복해서 찍는 "도배 모드"가 있어
  무단 도용을 더 강하게 막을 수 있습니다
- 매달 돈 내는 구독이 아니라, 한 번만 결제하면 평생 씁니다


■ 제가 직접 확인한 것 / 확인하지 못한 것 (솔직하게 말씀드립니다)

확인한 것:
- 코드 문법 오류 없음 (자동 검사 통과)
- 화면의 버튼/입력창 이름(id)과 실제 프로그램 코드가 정확히 연결됨
- 사진 크기 계산, 파일 이름 규칙 로직이 정확한 값을 내는지 자동 테스트로 확인함
- 웹서버로 실제 띄워서 모든 파일이 정상적으로 응답하는 것 확인함

확인하지 못한 것:
- 지금 작업 환경에는 화면(모니터)이 없어서, 실제 폰이나 브라우저 화면에
  손가락으로 눌러보면서 확인하는 "눈으로 보는 테스트"는 못 했습니다.
- 위 "지금 당장 1분 안에 테스트" 순서대로 먼저 본인이 한 번 써보시고,
  사진이 잘 처리되는지, 버튼이 잘 눌리는지 확인한 다음에 손님에게
  팔기를 권장드립니다.


■ 파일 구성
- index.html   : 화면 구성
- style.css    : 디자인
- app.js       : 실제 동작 로직 (여기서 Gumroad 설정 바꿉니다)
- sw.js        : 오프라인에서도 열리게 해주는 파일
- manifest.json: "홈 화면에 추가" 시 아이콘/이름 설정
- icons/       : 앱 아이콘 이미지
- 설명.txt      : 지금 읽고 계신 이 파일 5ㅗ1ㅁ2ㅁ3ㅁ4ㅁ
